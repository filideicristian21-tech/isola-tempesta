# Isola Tempesta

Battle royale in 3D che gira nel browser: **tu contro fino a 69 bot**, senza giocatori online e senza account.

Contiene violenza fantasy con armi e mostri in stile cartoon. Consigliato da 12 anni in su.

Isola Tempesta è un progetto indipendente, non affiliato a nessun editore di videogiochi.

## Come si gioca
Apri `index.html` da un server web statico (ad esempio GitHub Pages o `python3 -m http.server`).
Il file non funziona aperto direttamente da disco, perché usa moduli JavaScript.

## Privacy
Il gioco salva solo statistiche e impostazioni nel tuo browser (localStorage, chiavi `isolaT_*`). Non raccogliamo dati.
Il pulsante «Cancella i dati salvati» nella schermata iniziale le rimuove.
Il sito è ospitato su GitHub Pages: GitHub può registrare dati tecnici delle visite, come l'indirizzo IP, secondo la sua [privacy policy](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
